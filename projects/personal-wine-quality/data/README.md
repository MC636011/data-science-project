# Wine Quality data

The analysis script expects:

```text
projects/personal-wine-quality/data/winequality-red.csv
```

If the file is missing, `analysis.py` downloads it automatically from:

https://archive.ics.uci.edu/ml/machine-learning-databases/wine-quality/winequality-red.csv

Source page and license: https://archive.ics.uci.edu/dataset/186/wine+quality
