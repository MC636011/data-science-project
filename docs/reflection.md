# Reflection

This portfolio demonstrates my ability to organize an end-to-end data science project in GitHub. I used Python, pandas, NumPy, Matplotlib, and Seaborn to clean and analyze a large public flight-delay dataset, then turned the results into four labeled visualizations. I also strengthened reproducibility by documenting the dataset source, usage conditions, file layout, dependencies, and data-download steps. Preparing the GitHub Pages portfolio helped me communicate the research question, findings, limitation, project status, and repository link to a non-technical audience. Peer review encouraged me to make the charts and run instructions clearer. The next improvement is to test the full workflow in a clean virtual environment with a freshly downloaded CSV and add an automated data-validation step before running the analysis.
