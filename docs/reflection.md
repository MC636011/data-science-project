# Reflection

This portfolio shows my ability to organize different kinds of data science work in one repository while keeping individual and group projects clearly separated. My individual Wine Quality project demonstrates data cleaning, correlation analysis, and visualization using a classic public dataset. Assignment 01 demonstrates group work on a large U.S. flight-delay dataset, where I helped turn raw operational records into carrier, airport, time, and cause-based findings. Assignment 02 demonstrates group work on UK local-authority income inequality, including dispersion measures, Theil decomposition, and regional component analysis.

Across the three projects, I used Python, pandas, NumPy, Matplotlib, Seaborn, Jupyter-style documentation, GitHub, and reproducible project structures. The main improvement I made after feedback was to separate the group assignments and restore the Wine Quality project as my individual work. My next improvement is to test every project from a clean environment using freshly downloaded data and to add automated checks that confirm required files and figures are generated correctly.
