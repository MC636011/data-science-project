# Project proposal summary

**Project title:** Airline Flight Delay Pattern Analysis: A Multi-Dimensional Attribution Study of U.S. Domestic Flights

**Research question:** What drives U.S. domestic flight delays — carriers, airports, time of year, or causal factors?

**Planned analytical dimensions**
- Carrier: identify relatively punctual and delay-prone airlines.
- Airport: locate airports with unusually high delay rates.
- Time: measure seasonal differences in delay risk.
- Cause: compare airline-operational and weather-related delay shares.

**Planned outputs**
- Reproducible Jupyter Notebook and Python analysis script.
- Four readable visualizations.
- README with source, methods, findings, limitation, and reproduction steps.
- Portfolio page for GitHub Pages.
